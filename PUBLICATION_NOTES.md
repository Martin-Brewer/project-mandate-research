# Public snapshot notes

This repository is a curated public edition of the Project Mandate research project.

It is intentionally **not a mirror of the original private working repository and does not include that repository's Git history**.

## Included

- final research conclusion and project charter;
- key architecture and decision records;
- provisional authority-profile semantics;
- machine-readable conformance schema and vectors;
- standalone .NET black-box conformance runner;
- independently written Python containment verifier;
- selected experiment results showing the path from capability testing to the final kill decision.

## Intentionally excluded

- customer-discovery target lists and outreach drafts;
- personal/contact information;
- internal working notes and project-management backlog;
- intermediate private-repository history;
- generated development keys, temporary artefacts and machine-specific files;
- prototype source that is not required to understand or reproduce the published conformance experiment.

## Security/publication position

The published implementations generate or consume test/development material only. No production credentials or secrets should be committed to this repository.

The original private repository remains the complete working record. This repository exists for technical review, research and portfolio purposes.
